# dev-notes

这里放**当前仍然有效**的设计说明与重要原理，不是变更日志。

## 收录规则

- **只写现状**：说明系统现在怎么工作、为什么这样、边界在哪；
- **不保留已被取代的方案**：过时的传输、协议、目录布局、旧实现记录直接删除；
- **需要追溯历史时看 git 历史**，不要让过期文档继续误导读者；
- 文件命名：`[模块名]-[日期].md`，日期格式 `YYYYMMDD-hhmm`；
- 跨模块 / 项目级的记录用 `nenap-<日期>.md`；
- 正文以中文为主；接口细节以代码与各 crate 的 README 为准，这里重点写
  **因果链与不能从代码一眼看出的约束**。
